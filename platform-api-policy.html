Platform & API Use Policy

Last updated: January 2026

Purpose: This page explains how we use official platform APIs (e.g., WhatsApp messaging APIs) to deliver our service, and how we protect user data. We do not provide social listening, competitive intelligence, or audience surveillance.
1. Authentication & access
  • We use official platform authentication flows where required.
  • We do not ask users for passwords to third-party accounts.
  • Access is used only to deliver user-requested service functionality.
2. Data minimization
  • We only request and store data that is necessary to deliver the service (e.g., phone number for WhatsApp delivery).
  • We do not combine user data with external datasets for profiling or resale.
3. Prohibited uses
  • No scraping of private content.
  • No surveillance or monitoring of third-party user activity.
  • No selling of user data.
4. User controls
  • Users can stop using the service at any time.
  • Users can request deletion of data via User Data Deletion.
5. Security
  • We apply reasonable safeguards to protect stored data and access credentials where applicable.
  • We restrict internal access to authorized personnel only.
